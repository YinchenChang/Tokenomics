## 讀取結果與網址

1. 讀取結果只能填：已讀原文（R1，一手）、已讀一手文件轉載（R2）、已讀二手（R3）、讀不到：付費或需登入（R4）、讀不到：連結失效或被封鎖（R5）、找不到原始出處（R6）。「找不到」與「不存在」不同；不得把讀取失敗寫成來源不存在。
2. **R5／R6 的網址必須是摘要實際所在的頁面。** 搜尋結果摘要若無法對應到單一頁面（搜尋工具只回彙整摘要、未標逐項出處），不得替摘要指定網址，須在欄位註明「摘要所在頁面無法確定」，並列出出現過的候選頁面。
3. **原出處找不到值時，以「值＋產品名」反查**（例：「GB200 NVL72 rack 120 kW」「VR200 NVL72 7.8 million」），逐列記錄前輪登錄的網址是否與值錯配（值實際出現在哪一頁）。
4. 價格類多為分析師估計；可讀到者依 G0-7 為 2 級（二手且已讀），並註明立場與口徑（成本或售價；裸機或含網路；掛牌價或成交價）。

## 等級規則

- G0-7：1＝一手且已讀原文；2＝二手且已讀，或一手文件轉載；3＝只見搜尋摘錄、模型內建知識或待查核。
- S1 (a)：值相同（容差 0；換算後相同須列換算式）且已讀原文者列為升級候選，chat 端抽查後寫入；值不同、涉及 A 級或改變標記者逐筆交 Andy。
- H1（Decisions H1）：SemiAnalysis（含 InferenceX）不得為唯一依據；符合 (i) 已讀一手原始資料、(ii) 已搜尋同口徑第二來源並記錄查詢詞與結果、(iii) 口徑與方法已寫明者，上限 2 級，W1 標「待第二來源」。
- 區間型紀錄（Decisions G15；工作單稱「G1 規則」）：至少一個值讀到原文、基準落在已讀證據範圍內，即不為 3 級；未讀端點在備註標 Assumed。
