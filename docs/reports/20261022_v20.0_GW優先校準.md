## 1. 本輪做了什麼、為什麼

依工作單把 2025 年的校準順序改成「先 GW、再算 token」，並把回本判讀的成本口徑改成「全部算力持有成本」（付費、免費、訓練、研發都算），這是 Andy 10-21 14:55 與 10-22 的決定。

- 2025 平均上線 GW 取指數內插 1.128 GW（區間 1.0–1.25）。
- 服務 GW ＝ 平均 GW × 服務占比 0.462（0.30–0.75）。
- 付費 token ＝ 服務 GW ×（1 − 免費占比）× 每 GW 付費 token 產能 × 實際利用率 × 生產折減，基準 58.1 億 M tok；與支出帳（AL_DPaid）相比的 token 帳比值由 5.62 降為 **1.52**（0.45–5.26）。
- 回本：全部算力年持有成本 105.5 億（9.35–11.69）對營收 130.7 億，營收÷成本 1.239；所需 L 為 **0.807**（0.716–0.895）。
- 判讀列由「基準 L 0.759 對所需 L 0.756」改為「**未定（區間重疊；基準 L 0.759 對所需 L 0.807）**」；L 對所需 L 比值 0.940。

token 帳 5.62 → 1.52 的拆解（工作單 W6）：服務 GW 由 1.0566 改為 0.4624（×0.4377）；免費占比基準與 token 基準 r 的切換、支出基準 0.46 另列在 Cap_In P 節 token 帳列，未混在同一數字內。
