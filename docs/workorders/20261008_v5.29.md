## 2. Interface J 節：四層瀑布並列（工程類）

- 放在 Interface 最後一列之後。對 D 節七個營收列（IF_RevGW_Luna／Sol／Astra、IF_RevGWFleet 及其 Front 列）與 B 節三個 IF_TokGW_*，各做一組四列：
