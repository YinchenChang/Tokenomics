# 前沿 MoE 每 GPU 實測吞吐彙整（核對 roofline 模型用）

查證日：2026-10-21。唯讀網路研究，未修改任何 repo。
SemiAnalysis／InferenceX 僅列為旁證，不作為單一依據；每個結論至少有一個獨立來源（MLCommons 提交、NVIDIA／TRT-LLM 文件、LMSYS／SGLang、vLLM、DeepSeek 官方、雲端廠商）。

## 0. 先讀這幾點（口徑陷阱）

1. **MLPerf 的 tokens/s 只算輸出 token**；NVIDIA 說明「per-chip 不是 MLPerf 主要指標」（NVIDIA 2026-04-01 部落格原文）。DeepSeek-R1 為推理模型，輸出長，輸入佔比小，所以 MLPerf 的輸出 token/s 約等於總 token/s。
2. **TRT-LLM perf-overview 只列「每 GPU 輸出 token/s」**，是離線、無並發上限、固定 ISL/OSL、不受延遲約束的最大吞吐（trtllm-bench，PyTorch backend）。要換算總 token 須自行乘 (ISL+OSL)/OSL；下表標為「計算」。
3. **DeepSeek 官方揭露的「每節點 73.7k 輸入／14.8k 輸出」含快取命中的輸入**（輸入 56.3% 命中磁碟 KV 快取），不是純計算 token。
4. MLPerf 同一硬體不同提交者數字不一致（見 2.4 節），不要只取單一格。
5. 沒有任何一個來源同時給出「IT 電力」基準的 tokens/s/MW；NVIDIA 公布的每 MW 數字未註明 IT 或設施（見第 5 節）。

## 5. 生產環境利用率與實際吞吐揭露

### 5.1 DeepSeek 官方（2025-03-01 公布，量測日 2025-02-27 12:00 至 02-28 12:00 UTC+8）
來源：https://github.com/deepseek-ai/open-infra-index/blob/main/202502OpenSourceWeek/day_6_one_more_thing_deepseekV3R1_inference_system_overview.md ；性質：DeepSeek 官方揭露（自報，未經第三方稽核）。

| 項目 | 數字 |
|---|---|
| H800 節點（每節點 8 GPU） | 尖峰 278；日均 226.75 |
| 租用成本假設 | $2／GPU 小時；日成本 $87,072（226.75×8×24×2 驗算相符） |
| 每節點吞吐（服務期間） | 輸入約 73.7k tok/s（含快取命中）；輸出約 14.8k tok/s；每用戶輸出 20–22 tok/s |
| 當日總量 | 輸入 608B（342B，56.3%，命中磁碟 KV 快取）；輸出 168B；平均 KV 長度 4,989 token／輸出 token |
| 理論營收／成本利潤率 | 按 R1 定價理論日營收 $562,027；利潤率 545%。實際營收明顯較低（V3 較便宜、部分服務免費、夜間折扣） |

**自行推算（計算）**：
- 每 GPU：輸出 14.8k／8 = 1.85k tok/s，輸入 73.7k／8 = 9.2k tok/s，合計約 11.1k tok/s/GPU（含快取命中輸入）。
- 日均實際：輸出 168B／86,400 s／226.75 節點 = 約 8.6k tok/s／節點（約 1.07k／GPU）；輸入 608B 同法約 31.0k／節點。約為揭露峰值速率的 58%（輸出）與 42%（輸入）。即「日均有效吞吐／服務期間速率」約 0.4–0.6，且節點數本身已隨負載日夜調度（尖峰 278，均值 226.75，均值／尖峰 = 82%）。
- 不含快取命中的輸入：（608B−342B）= 266B，約 13.6k／節點。
- 對照開源重現：SGLang 96×H100 每節點 22.3k 輸出、52.3k 輸入（無生產負載型態與快取）；Decode 單點 DeepSeek profile 18,598／節點。
