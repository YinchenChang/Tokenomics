## 4. 網站變更

- **Block 2 頁新增「推導鏈」區塊**（依所選層級；欄＝世代，欄名取 `DRV_Gen`、`DRV_Tier`）。列依你指定的順序：decode FLOPs/token（`DRV_FlopDec`）→ prefill FLOPs/token（`DRV_FlopPre`）→ 每 GPU 權重（`DRV_WeightGB`）→ 每步固定延遲（`DRV_TfixMs`）→ 每序列每步（`DRV_SeqMs`）→ 每序列綁定項（`DRV_SeqBind`）→ 採用批次（`DRV_Batch`）→ 綁定約束（`DRV_Bind`）→ decode tok/s（`DRV_DecTokGPU`）→ prefill tok/s（`DRV_PreTokGPU`）→ prefill GPU 占比（`DRV_PreShare`）→ 每架總 tok/s（`DRV_RackTok`）→ 每 GW 總產出（`DRV_GWTok`）→ decode $/M 速覽（`DRV_CostDec`）→ 能量閉合比（`DRV_Close`）。標籤與單位取自 Excel；單位為 % 的列以百分比顯示。
- **層級名稱**（Luna（低層）等）改取 `DRV_Tier`；**世代與成本情境表頭**改取 `IF_HdrGen`、`IF_HdrCost`；不再以欄 A 標籤定位。

- 兩張表改為依列數設定高度（不再需要在表內捲動）；總覽頁的 Block 1 表改依 Excel 列序排列（原本以文字排序，列序會錯）。

## 5. 需要 Excel 端處理的事項（本輪未改 Excel）

第 1 輪提出的問題，在 v5.3 已逐項確認處理：H 節量測平台列 ✔；表頭與 Calib 具名範圍 ✔；推導鏈具名範圍 ✔；decode 標籤已標明「含思考 token」✔（仍未分列思考與可見輸出，但 Excel 已明說合併）；Checks 頁 E9、E10 改引用 C 欄 ✔；「SLO 不可達」備註已更新 ✔；已無「v4 Config」引用 ✔。

本輪新發現：

1. **CAL_ 只提供「點位標籤、量測平台、比值」三項，網站的驗證表因此比第 1 輪少了幾欄**：世代、軟體／日期、每用戶速度、實測 tok/s/GPU、模型 tok/s/GPU、以及口徑（F 節是總 token、H 節是輸出 token）。沒有這幾項，讀表的人看不出比值是怎麼來的。建議 Excel 端補：`CAL_F_Gen`、`CAL_F_Meas`、`CAL_F_Model`、`CAL_H_Gen`、`CAL_H_Meas`、`CAL_H_Model`（可含口徑說明）；是否補請 Andy 決定。
2. **F 節的點位標籤（`CAL_F_Label`）是「用途」欄**（擬合點 1、驗證、驗證（舊軟體）…），多個點的標籤相同或不含世代與軟體資訊，單看無法分辨。H 節的標籤（`GB300 interactive（v6.1）`）則已自我說明。建議 F 節比照 H 節，標籤含世代與軟體。
3. `DRV_CostDec` 只有基準成本情境（Excel 列標籤已註明）；網站於表下方註記其不隨成本情境選擇器變動。若要跟隨選擇器，需要每個成本情境各一列的具名範圍。
