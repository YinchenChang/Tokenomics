# TPU／Trainium3 產出比查核（2026-11-04；Andy 11-04「這個要優先查核，莫非我們'各晶片最高原生精度'的假設錯了?還是有其他原因」）

## 結論
- v21.9 的 TPU 0.35、Trn3 0.14 **與 TK 自己的 roofline 引擎一致**（不是算錯）：TPU v7 規格代入引擎 Hopper 欄（非校準錨點、FP8 服務）得 0.27–0.31（Luna／Sol／Astra）。
- 問題在引擎的隱含前提：**TK 引擎把推論當成算力受限**——VR200 改 FP8 產出剛好減半（2.01–2.07 倍）；TPU 只把權重改 4 bit（W4A16）產出幾乎不變（0.30 → 0.31）。在此前提下「原生精度」等於給 TPU 固定 2 倍懲罰。
- 外部證據不支持「全程算力受限、4 bit 好處只歸 NVIDIA」：InferenceX 實測 Blackwell FP4 對 FP8 吞吐 2.2–8.2 倍（超過峰值比，含省頻寬、增並行的效果）；Google 人員稱 MoE 推論轉向記憶體受限；每 kW HBM 頻寬 TPU v7 為 VR200 的 0.97–1.11、容量 1.94 倍；TK 對 Hopper 的已知低估（模型約為實測 0.27 倍）與此一致。
- 另有**世代錯配**：TPU v7 Ironwood 的同代是 GB300；VR200 的同代是 TPU 8t／8i（2026-04 發表，原生 FP4，功率未公布）。Anthropic 2026-04 新合約即「next-generation TPU」。
- 第三方實測分歧：SemiAnalysis AgentX（2026-10，Preview）TPU v7 FP8 每 TCO 效能為 GB300 NVFP4 的 1.42–1.67 倍 → 串接 VR200 得成本比 0.84–2.11（基準 1.44）；同機構 2026-09 InferenceX 則 GB300 好約 30% → 2.67。結果對軟體版本敏感。
