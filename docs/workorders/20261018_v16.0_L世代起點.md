## 定義（寫入 Cap_In 新節的說明列與 README）
L＝某一世代硬體在其壽命期 T 內，token 單價相對該世代**起點**單價的平均（跌價＋降級）。每個世代從自己的起點算。2025 年是**校準錨點**（觀察營收與支出的年度），不是 L 的起點。現行 `L1_LTotal` 的公式就是「新世代、起點＝第 0 年」的 L，保留不改。
