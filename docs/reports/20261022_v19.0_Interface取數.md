## 0. 一句話結論

## 7. 待 Project 判斷

1. **節字母 K → N**：工作單稱「K. P×Q 取數」，但 Interface K（v8.0 IF_AllocServeGW_Tok）、L（v10.0）、M（v14.0）已存在，本版取 N，名稱與列內容完全照工作單。若要改字母只是標題文字。
2. 其他世代的「重解生產折減比」仍只有 VR200（`IF_FleetProdRatio_VR200`），其他世代下游暫用線性 `IF_ProdDerate`（工作單已列待判斷，留下一版）。
3. 服務占比、免費占比用既有的 `IF_ServeShare`（0.41）、`IF_FreeShare`（0.46），本版不新增名稱；`IF_MixFree_*` 的基準（0.90／0.10／0）是層級占比，不是免費占比。如需把「服務占比 ×（1 − 免費占比）」併成單一名稱，請另行指示。
4. 工作單第 W1 表中 `IF_PxEffMix` 註記為「2026 快照」，實際讀 `Cap_In!$C$90`（層級組合、有效牌價）；`Cap_In!$E$205`（L1_PxEff_2026 讀的格）數值相同（1.96068）。未改動，僅提醒兩者是不同儲存格。
