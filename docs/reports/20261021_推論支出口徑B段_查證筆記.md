# OpenAI 2025 推論支出口徑 B 段（75 / 84 / 126 億）

查證日：2026-10-21。唯讀，僅用 WebSearch／WebFetch。多數頁面經摘要模型轉述，未見原文；FT、The Information、Fortune 原文皆未直接讀到（付費牆／未取得）。

## 結論先行
1. 三個數字不是同一件事的三個估計，是三種不同範圍：75 = 審計後會計科目「營業成本」；84 = 管理層（投資人資料）定義的「推論」全年成本，含免費用戶；「126」= 我找不到出處，Zitron 公開的 Microsoft 端序列是累計 124.3 億（CY2024 至 2025Q3），2025 前三季 86.7 億，兩者都不是 2025 全年。
2. 84 比 75 多的 9 億，最可能去處（推測）：被審計報表歸在營業成本以外的服務性算力（R&D 或 S&M 內的 Microsoft 帳單，免費用戶／評測／研究性推論），其次是分類與口徑（應計 vs 現金）。證據強度：弱到中。無任何來源直接對齊 75 與 84。
3. 建議主口徑用 75（審計 COR），84 作敏感度，並在回本判讀上承認：現行比值 1.003 落在口徑不確定性（所需 L 0.675 vs 0.756）之內，不應宣稱「剛好回本」。

## 二、三者對齊的交叉證據
1. Microsoft 端前三季「推論」86.7 億 > 審計全年付 Microsoft 的 COR（60.47 億）> 也高於 84 億全年。含意（推測）：Microsoft 端「推論」類帳單的範圍，大於 OpenAI 會計上的服務成本，可能含研究／評測／合成資料等歸在 R&D 的推論，或含非現金額度。
2. H1 2025：The Information 報 COR 超過 25 億（Zitron，https://wheresyoured.at/where-is-openais-money-going ）；同期 Microsoft 端推論 50.2 億，約 2 倍。H1 2025 COR 25 億 → 全年 75 億，意味 H2 約 50 億。
3. 未找到任何 Zitron、FT、The Information、The Register、Sacra 或分析師把 75、84、126 三者明確對齊。TechTimes 與 Luminix（https://www.useluminix.com/reports/company-overviews/openai-financial-fact-sheet-june-2026 ）明確指出兩者未調和（"does not reconcile"）。

## 三、84 比 75 多 9 億的去處（推測，依證據強度排序）
1. S&M 或 R&D 內的服務性算力（中偏弱）：S&M 同年增 418% 至 5.73B，其中付 Microsoft 0.527B；R&D 付 Microsoft 10.59B。若免費用戶推論或研究性推論有一部分記在這兩科，管理層的「推論」會大於審計 COR。0.527B 單獨已占 9 億缺口的約 59%。無來源明說。
2. 口徑與時點（弱）：應計 vs 現金、額度抵減、供應商差異（非 Microsoft 供應商的推論）。無證據。
3. 管理層「調整後」口徑含非 GAAP 調整（弱）：33% 毛利率不能由 7.5 或 8.4 任一個重現。
4. 計量誤差或四捨五入（很弱）：8.4 為約數。
不排除 84 與 75 實質同一事物、差異只是後者缺少某些支出，但無可驗證支持。

## 五、對 Tokenomics 的建議
- 主口徑：75 億（審計 COR）。理由：唯一經審計且有金額與組成片段（80.6% 付 Microsoft）的口徑；Zitron 與 Fortune/TechSpot 等數家報導數字一致（但同源）；與 130.7 億美元營收同一會計年度、同一報表，比值內部一致。
- 敏感度：84 億（管理層推論，含免費用戶）。它更接近「服務用戶推論」的概念，但是單一來源鏈（The Information 二手），範圍定義未知，且與其自身 33% 毛利率不能對上。
- 126 億：不用於回本比值。非全年、含研究推論與可能的非現金額度（推測），且我查不到該數字出處。
- 所需 L（營收 130.7 億×0.85＝111.1 億）：75 億 → 0.675；84 億 → 0.756；126 億 → 1.134。現行 L÷所需 L 為 1.003，換成 75 億或 84 億會落在約 1.0 到 1.1 之間或約 0.9 以下，取決於你的 L 值；結論：回本判讀對口徑敏感度（約 12%）大於 1.003 的餘裕，應以區間呈現，不宜寫「剛好貼線」。
- 不確定性：(a) 75 是否完整涵蓋免費用戶推論（未知）；(b) 84 的供應商與現金／應計範圍（未知）；(c) 審計財報的 COR 附註（組成、額度、Microsoft 對價處理）我未取得，若能從 FT 原文或 Zitron 付費段落取得，可大幅縮小差距；(d) 本次所有轉述多為摘要模型讀取，數字已盡量跨頁對照，但屬二手。
