## 1. 本輪做了什麼、為什麼

1. **M1（D9）快取命中進產能**：服務端的 prefill 只需處理「新鮮輸入」（ISL × (1 − 快取命中率)），不必重算已快取的部分。過去產能端（Perf）把整段 ISL 都算進 prefill，與成本端（已用快取價）不一致，產能因此偏低。現在 TTFT、每請求 GPU 秒、prefill GPU 占比都只計新鮮輸入。訓練端的批次推論（Perf_Batch）沒有服務快取，維持不變（工作單要求 Training 全部數值不得變）。
2. **M2**：付費占比（Cap_In 第 87 列）原本用「支出口徑」免費占比，卻乘在 token 上，口徑不一。改為 token 口徑 1 − `AL_FreeShare`（0.54 → 0.40）。
3. **M3**：κ（API 實收對牌價的倍數）原本只乘在 token 端，現在也乘在價格端（Cap_In 第 90 列與 `CAP_Price25Mix`），價格與 token 同時帶 κ。基準 κ＝1，所以基準值不變。
4. **M4**：`IF_AmortRev_*`（營收權重攤提）的分母由「付費＋免費 token」改為付費 token，與 `IF_AmortBU_*` 一致。
5. **M5**：回本判讀的兩種讀法並列，並拆解差距（見第 6 節）。
6. **M6**：需求路線的 m（`L1_MImplied`、`MImplied_Ext`、`MAPI`、`MSub`、`MSeat`）改用 2025 年度單價；`IF_AllocQ1_R2` 的服務側改支出路線；`L1_ExtServeGW` 推算值改回支出路線。
7. **M7**：下游契約文件改寫為 v0.5。
8. **版號判為 v9.0（不是 v8.1）**：`IF_AllocQ1_R2`、`IF_AmortRev_*`、`L1_ExtServeGW` 的定義改變，屬契約改變，依第 4 節版號規則為主版。此判斷請 Project 確認（第 9 節）。

**M5：兩種讀法**（v9.0 基準）：

- 字面讀法 `L1_LReqFleet`＝2025 機隊損益兩平 0.572 ÷（`IF_Util` 0.6 × `CTL_ProdDerate` 0.85 × `L1_MFleet` 0.5505）＝**2.037**
- 恆等式讀法 `L1_LReqFleet_Id`＝支出路線服務 GW 的持有成本 ÷ 營收＝**0.756**
- 差 **2.6946 倍**，大於 10%，所以依工作單預設以恆等式讀法為主、字面讀法並列。判讀欄文字：「恆等式讀法為主：未回本（L_total 0.64 對所需 L 0.76）；字面讀法 2.04（未回本）並列；兩種讀法差 2.7 倍，來源見 2-4 報告」。兩種讀法的結論都是「未回本」（L_total 0.643 低於兩個所需 L）。
- **差距來源（拆解殘差 7e-16，即完全解釋）**：2.6946 ＝ 4.5167 × 0.8730 × 0.6833：
  1. **4.5167**：機隊每 GW 營收（`IF_RevGWFleet`）只計付費服務占比，B4_Serve × (1 − B4_Free)＝0.41 × 0.54＝0.2214 GW，倒數 4.517；字面讀法的分子是整個機隊的損益兩平，分母卻只含這 22% 的營收。
  2. **0.8730**：支出路線 token 裡付費占比＝1 ÷ (1 + r × 付費產能 ÷ 免費產能)＝0.873，免費 token 稀釋。
  3. **0.6833**：實際利用率 `AL_UtilActual`（0.41）對 `IF_Util`（0.6）。
  - 換句話說：字面讀法要成立，m 必須是 1.483（目前 0.5505，差 2.69 倍）；兩種讀法的差距不是計算錯誤，而是 m 的 token 口徑（支出路線推得的實際 token）與機隊營收的口徑（滿載、僅付費份額）本來就不同。

## 7. `d9_cache_cap_off` 核對結果

## 9. 待 Project 判斷（工作單沒寫到或寫得不清楚，我沒有自行決定）

1. **版號 v9.0 或 v8.1**：我判為 v9.0（契約名稱 `IF_AllocQ1_R2`、`IF_AmortRev_*`、`L1_ExtServeGW` 定義改變）。若 Project 認為只算次版，需重新命名（檔名與 README 版號、`CURRENT`）。

5. **M2 的 `AL_FreeShare` 用在 Epoch 全體 token**：Epoch 每日 token（SRC_DEM_013）是全產業總量，其免費占比未必等於 ChatGPT 的 0.6。我依工作單用 `AL_FreeShare`（0.6，區間 0.4–0.8），只影響 `L1_MImplied_Ext`，請確認。
