## 2. 每則訊息 token 數
OpenAI 未揭露 ChatGPT 每則訊息 token 數。找到的都是估計或不同平台資料：
- Epoch（2025-09 前後，Gradient Update）：「the mean message length is four thousand tokens long」，API 另加約四分之一；40 億則 × 4,000 ≈ 16T，加 API 約 20T/日；混合中位約 19T/日；算力法 10–100T/日。這個 4,000 是 Epoch 的假設，不是量測；我們模型的 4,000 很可能與此同源，不可視為獨立證據。https://epoch.ai/gradient-updates/how-many-digital-workers-could-openai-deploy （第三方）
- Epoch 能耗文：典型輸出 500 token（「somewhat pessimistic」），Chiang 等實測平均回應 261／269 token；輸入手打短問題可忽略；長文件 1 萬或 10 萬輸入 token 為情境；o1／o3-mini 輸出約 GPT-4o 的 2.5 倍（約 1,390 對 540，僅 5 題非代表性）。https://epoch.ai/gradient-updates/how-much-energy-does-chatgpt-use （第三方）
- LMSYS-Chat-1M：每輪 prompt 平均 69.5、回應 214.5 token，平均 2.0 輪（Llama 2 tokenizer）。arXiv 2309.11998 Table 1 （學術，不含歷史重送）
- WildChat（ChatGPT 使用者對話）：使用者每輪 295.58、機器人每輪 441.34 token，平均 2.54 輪。arXiv 2405.01470 Table 1 （學術）
- OpenRouter／a16z 100 兆 token 研究（API 平台，非 ChatGPT）：平均 prompt token 約由 1.5K 增至逾 6K；completion 約由 150 增至約 400；序列總長由不到 2,000（2023 末）增至逾 5,400（2025 末）；推理模型占全部 token 逾 50%（是路由到推理模型的 token 占比，不是推理 token 占輸出比）。https://arxiv.org/html/2601.10088v1 （第三方）
- Nathan Lambert（Interconnects，2025）：兩年前一次 ChatGPT 查詢約 100–1K token；Deep Research 一次約 1M token 推論（作者與朋友估計）；推理模型可到數萬。https://www.interconnects.ai/p/people-use-ai-more-than-you-think （第三方）
- tokensperday.com 的 OpenAI「需求通道」＝公布的 API 21.6T/日 ＋ 訊息數 × 每則 token（其 token/則數值頁面未列，輸入檔 channel_inputs.csv 未讀）：全 OpenAI 約 22.9／26.6／44T/日（低／中／高）；整合 21.6／32.6／67T/日。https://tokensperday.com/estimates/ （第三方，個人網站，品質待查）
- 未找到：OpenAI 官方的輸入／輸出／推理 token 拆分；ChatGPT 系統提示、歷史重送、檔案、搜尋結果的平均長度。

## 6. 付費／免費用戶 token 占比
- OpenAI 未揭露付費與免費用戶的 token 或訊息占比；NBER 論文按方案記錄但未報量差。
- 人數：2026-02 消費者訂閱逾 5,000 萬，付費企業用戶逾 900 萬，WAU 逾 9 億（約 5.6%，OpenAI，經 sqmagazine 轉述）；2026-03-31 官方「over 50 million subscribers」。2025-01 Pro 占消費者營收 5.8%（Earnest，第三方）。
- 每人用量差異：未找到可信揭露。
- 因此 0.4 付費占比沒有外部支持，且與「付費者約占 5% 人數」相比，隱含付費者人均用量高很多倍，需自行論證。
