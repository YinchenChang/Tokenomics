## 結論先行

1. **1.8 沒有被直接證據支持，也沒有被推翻：不確定。** 2025 年 OpenAI 在 Azure 的實付單價（每 GPU 小時、每 GW·年、或金額÷同期容量）**仍然找不到**。新找到、可換算成「每 GW·年 ÷ 9.353」並可用來判斷的獨立錨點有 6 組（E01、E05、E06、E07、E08、E10；同源已合併），分成兩群：
   - **接近 1.0–1.5 倍**：CoreWeave 已實現單價 0.93–1.10（公司申報）、IREN 賣給 Microsoft 的合約 1.04（公司公告）、Oracle 供應商毛利推算 1.2–1.7（外流文件／管理層目標）、2024 年 Microsoft 對 OpenAI 的 A100 報價換成功率口徑 1.3（1.1–1.5；二手轉述）。
   - **高於 1.8**：Oracle–OpenAI 合約 1.4／2.1／3.1（最低／基準／高，未來價）、Azure 公開牌價 1.5（H100 Spot）至 12.7 倍（GB200 隨需）。
   → 獨立證據的重心在 **1.0–1.5 倍**，1.8 落在證據範圍的中上段，不在中心；0.85–2.3 的區間被容許。
2. **為什麼仍然需要 1.5 以上：三角約束。** 2025 全部算力支出 204 億＝平均 GW × 計價倍數 × 持有成本 9.353 × （口徑 s）。把 GW 放到最前重的極端情境（80% 新增容量在年初完成）平均也只有 **1.45 GW**，此時 s＝1.0 需要倍數 ≥ **1.51**，s＝0.79 需要 ≥ **1.19**；用線性內插 1.25 GW 則需 1.75（s＝1.0）。也就是說：**若價格證據的中心（1.0–1.3）為真，2025 的 204 億就解釋不完**，差額必須由 s（口徑）吸收，或 AL_FleetHold 低估。1.8 是在 GW＝1.128、s≈0.9–1.0 下的殘差，不是量到的價格。
3. **證偽條件**
   - **(a) 平均或季度上線 GW ≥ 1.8：未觸發。** 端點 0.6→1.9 GW，且 Altman 2025-07-20 說年底前上線「well over 1 million GPUs」（TK 每 GW 約 63 萬顆 → 1.9 GW≈120 萬顆，一致）；Epoch H100e 2024 年底 38.4 萬→2025 年底 174 萬，線性平均折成約 1.16 GW。要平均到 1.8 GW，新增的 1.3 GW 必須在年初幾天內全部到位，與端點、與 Zitron 季別 Azure 推論金額（Q1 20.8 億→Q3 36.5 億，逐季上升）都不符。
   - **(b) Azure 對 OpenAI 的單價揭露 ≤ 2 美元／GPU 小時：字面上有一筆、實質未明確觸發。** 唯一一筆是 2024 年的 A100 報價 1.30 美元（The Information 經 DCD 轉述）；它是 2024 年、A100 世代、二手轉述。換成 2025 機隊口徑（保持每 IT-kW 持有成本跨世代不變，Assumed）約 **2.2 美元／GPU 小時（1.9–2.6）**，剛好橫跨 2 美元門檻。**交 Project 判斷是否算觸發**（建議預設：不算，理由是世代與年度不同，且換算值基準高於 2 美元）。

### 讀表重點
- **最接近「實付價」的 E01 偏低（1.3 倍）**，但是 2024／A100／二手。若 2025 的折扣幅度與 2024 相同，E02 顯示結果會遠高於 2.3 上限，所以兩個方向都不能定論。
- **E07、E08 說明長約租賃在 1.0 倍附近**；Azure 賣給 OpenAI 若是 1.8 倍，等於在 Microsoft 的成本（約 1.0 倍，E08）上加價約 73%，高於 Oracle 目標毛利（35–40%→1.5–1.7 倍）。
- **E10 說明 1.8 倍遠低於牌價**：相當於 H100 三年預留價再折 51%，或 GB200 一年預留價再折 78%。大客戶折扣的公開說法（部落格稱 30–50%，無來源基礎）不夠解釋，須有 OpenAI 特殊條件。
