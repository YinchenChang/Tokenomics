## Q1：Fairwater 與 OpenAI 容量（FY27 Q1，2026-07～09）

### 一手：新聞稿與 10-Q（company-models 抽取；官方頁 https://www.microsoft.com/en-us/investor/earnings/fy-2027-q1/press-release-webcast）
- **新聞稿（2026-10-28）。** 營收 923 億美元、成長 19%；Microsoft Cloud 639 億、成長 30%；Azure 成長 48%；商業 RPO 成長 73% 至 6,770 億。全文無 Fairwater、GW、容量數字；OpenAI 只出現在非 GAAP 調整（OpenAI 投資淨利 2.07 億）。IR 頁 WebFetch 結果同：無 Fairwater、無 GW。
- **10-Q 關係人附註。** OpenAI 為權益法被投資公司（約 24%，as-converted），依 ASC 850 揭露：當季來自 OpenAI 商業安排的營收 100 億美元，「inclusive of revenue-sharing payments」；應收 72 億（6 月底 60 億）；出資承諾 130 億、已出資 120 億。未拆分 Azure 消費與分潤；未提站點、GW 或容量。
- **10-Q RPO 附註。** 總 RPO 6,830 億、商業 6,770 億；加權期間約 2.3 年；12 個月內認列約 30%。未揭露 OpenAI 占比（B 段 F04 的「約 45%」是 FY26 Q2 法說的說法，本季未更新）。
- **10-Q 風險因子。** 管理基礎設施容量受限時，可能調整容量分配、部署優先順序、價格或商業安排；策略夥伴在部分情況下也是 Azure 大客戶。無比例、無站點。是否為本季新增文字：未與 FY26 10-K 比對。
- **10-Q 租賃與現金流。** 購置 PP&E 現金 393.67 億（去年同期 193.94 億）；尚未起租租賃 3,646 億，多為資料中心，FY27–FY34 起租；當季以融資租賃取得之使用權資產 51.92 億（去年同期 91.47 億）；融資租賃負債 709.73 億。
- **10-Q 產品別營收。** Azure 331.65 億（去年同期 223.84 億）；新分部 Agents and Infra。
- 10-Q 全文搜尋 Fairwater、Anthropic、gigawatt：皆無。

### 二手：法說逐字稿（2026-10-28 美西 14:30）
來源：TradingKey https://www.tradingkey.com/news/transcripts/262249601-tradingkey 、SingjuPost https://singjupost.com/transcript-microsoft-q1-2027-earnings-call/ 。兩份皆查無 Fairwater、Atlanta、Wisconsin、superfactory、gigawatt、megawatt、superintelligence、neocloud；兩份皆查無 RPO 中 OpenAI 占比或「排除 OpenAI」的 RPO 成長。
- **Nadella 開場。** 需求加速，當季在五大洲新增 24 座資料中心；首批 NVIDIA Vera Rubin GPU 已上架；新 GB300 的交付時程縮短約兩成。無 MW／GW。
- **Nadella 答 Adam Wood（Morgan Stanley）。** 「we have one pool」（TradingKey）；希望容量池有效率且可互換，依需求訊號把容量配給最高價值用途。未提 Fairwater 或 OpenAI。
- **Hood 開場。** 需求仍超過供給；capex 452 億，部分第三方容量交付延遲；約四分之三為短期資產（CPU、GPU）；融資租賃 74 億；PP&E 現金 394 億。
- **Hood 展望。** Azure 固定匯率成長 49–50%；部分第三方 GPU-as-a-Service 合約延到下半財年；Q2 capex 逾 500 億；曆年約 1,700 億。
- **Hood 答問。** 當季能把更多配額放進 Foundry；CPU 機隊閒置容量被變現。
- **Gabriela Borges（Goldman Sachs）提問。** 稱 OpenAI 占當季營收 11%（與 10-Q 100 億 ÷ 923 億＝10.8% 一致）；Nadella 的回答談模型路由與 MAI，未談容量。
- **Nadella 談 MAI。** MAI-Base-2 預訓練已完成，將用於後續 MAI 模型；未給 GPU 數或站點。
- **Nadella 答 Borges。** 希望 Anthropic 與 OpenAI 為每個工作負載競爭（模型路由）；不是容量說法。
- TradingKey 版本的商業 RPO 作「677 million」，與 10-Q 的 6,770 億不符，判為轉錄錯誤，以 10-Q 為準（SingjuPost 版本的金額未核）。
