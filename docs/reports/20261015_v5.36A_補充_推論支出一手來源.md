## 2. 交叉核對（Derived）

1. **營業成本 75 億（S3）與 84 億（S2′）同一量級**：調整後毛利率 33% → 成本約 13.07 × 0.67＝87.6 億；查核報表毛利率約 43%（75 億）。差額可能是「調整」口徑或非推論的營業成本，未能拆分。
2. **算力毛利 70%（S4）＋免費推論 39 億**：付費推論約 13.07 × 0.3＝39 億，加免費 39 億（`SRC_DEM_005`）＝約 78 億，落在 75–88 億之間。
3. **Microsoft 端 126 億（S1′）對 OpenAI 帳上付 Microsoft 的營業成本 60.5 億（S3）**：Microsoft 稱為「推論」的金額，約一半沒有進 OpenAI 的營業成本。可能的解釋：
   - (a) 研究用推論（強化學習 rollout、評測、合成資料）在 OpenAI 帳上列研發（付 Microsoft 研發 105.9 億，足以容納）；
   - (b) Microsoft 文件以牌價或含抵用金計；
   - (c) Microsoft 所說「不太正確」。
   
   三者都指向同一方向：**用於服務用戶的推論支出低於 126 億**。
4. **反方證據**：S1 不含其他供應商，若 OpenAI 在 CoreWeave 等也有大量推論，總推論會高於 126 億，與 84 億衝突。但 S3 的營業成本 75 億已含所有供應商（非 Microsoft 部分只有 14.5 億），所以非 Microsoft 的服務推論不大；這個反方證據在 S3 下不成立。

## 5. 結論與建議預設（待 Andy 決定）

1. **推論支出：主值 84 億，區間 75–88 億；126 億改為對照列。**
   - 理由：OpenAI 端三個來源（查核報表營業成本 75 億、投資人文件毛利率 33% 換算 88 億、算力毛利 70% 換算約 78 億）互相一致；Microsoft 端 126 億有一半無法對應到 OpenAI 的營業成本，最可能是研究用推論列在研發。
   - 這與你和 Copilot 的傾向相同，但依據是查核報表，不是傾向本身。
2. **計價倍數：基準由 2.0 改 1.3，區間 1.0–1.6。**
   - 理由：Oracle 毛利率換算上限約 1.16（且尚未計資本成本）；Microsoft 對 OpenAI 的計價未找到，保留高端 1.6。
   - 1.5 也可接受（A 段原建議）；兩者差異：84 億下 m_fleet 0.79 對 0.91。
3. **含義**：取 84 億＋1.3，m_fleet 0.79、實收 1.55 $/M、缺口 2.21。
   - 支出改 84 億與計價倍數下修**互相抵銷**，缺口仍約 2.2 倍，閉合仍需要需求端 τ 上修或 κ 低於 1。
   - L 基準下回本，L 低端（需 1.69 $/M）下不回本。
4. **仍未解**：Microsoft 稱為推論的 126 億中，研究用推論的比例；它屬於研發算力，若確認，會反映在研發 GW（`L1_Ans1`–`Ans3`）而不是服務 GW。
