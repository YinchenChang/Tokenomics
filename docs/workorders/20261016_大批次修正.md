### G4 MLPerf server 改為軟上限
- **範圍**：V1、V2、V3（MLPerf server 類）。
- **新判定**：比值 ≤1 為通過；>1 為「警示（MLPerf server 為 p99 延遲口徑，模型取平均；同條件 TensorRT-LLM H200 為 MLPerf v5.1 的 2.6 倍）」，不計入失敗。
- **新增名稱** `CHK_VerifyWarn`，並維持恆等式 `CHK_VerifyPass ＋ CHK_VerifyFail ＋ CHK_VerifyWarn ＝ CHK_VerifyTotal`。
- **interactive 類（V4–V6）維持硬上限。** 理由：interactive 是低延遲口徑，與模型的服務端口徑較接近。這是 chat 端預設。
- 下游契約：說明驗證計數多了「警示」類。
