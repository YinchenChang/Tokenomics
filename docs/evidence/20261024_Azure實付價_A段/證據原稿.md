## E01／E02（同源 S1）The Information 2024，經 DCD 與 Simon Willison 轉述
- 網址：https://www.datacenterdynamics.com/en/news/openai-training-and-inference-costs-could-reach-7bn-for-2024-ai-startup-set-to-lose-5bn-report/ ；https://simonwillison.net/2024/Jul/25/amir-efrati-and-aaron-holmes
- 取得方式：頁面摘述（DCD）、頁面摘述（Willison）。
- 摘錄（DCD，引號內逐字）："For both inference and training, OpenAI gets heavily discounted rates from Microsoft Azure."；"Microsoft has charged OpenAI about $1.30 per A100 server per hour, way below normal rates."；"OpenAI has the equivalent of 350,000 servers containing Nvidia A100 chips for inference"；OpenAI 預期當年「nearly $4 billion」用於 Microsoft 伺服器跑 ChatGPT 推論。
- 摘錄（Willison 轉引 The Information，引號內逐字）："That cluster has the equivalent of 350,000 Nvidia A100 chips, this person said."
- 解讀：DCD 寫『A100 server』與『350,000 servers』，但 The Information 原句（經 Willison 轉引）寫『350,000 Nvidia A100 chips』。兩種單位的金額都是 35 萬×1.30×8760＝39.9 億，與『nearly $4 billion』吻合，所以金額不能用來分辨。分辨依據是容量：若 35 萬是 8 顆伺服器，則為 280 萬顆 A100，約 2.6 GW，遠超 OpenAI 2024 年底總容量 0.6 GW；故採『每顆晶片 1.30 美元』。這是推論，不是原文。
- 對照：Zitron 內部文件 2024 全年 Azure 推論 37.67 億美元（見 E00），與 39.9 億差約 6%。
