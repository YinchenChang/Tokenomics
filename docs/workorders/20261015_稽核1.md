## 2. 每格要填的欄位（填入 C7 清單的空白四欄，另加四欄）

| 欄 | 內容 |
|---|---|
| 代表什麼物件 | 一句話。例如「Sol 層級代表模型的啟用參數（以 DeepSeek V4-Pro 為代理）」 |
| 時點 | 這個值所描述的時間點或期間。例如「2026-04 模型卡」「2025 全年平均」「無時點（物理常數）」「不明」 |
| 應否隨世代或時間變化 | 三選一：是／否／不確定。另附模型的實際做法：有世代維度、單一值套用全部世代、或單一值套用全部年度 |
| 口徑是否與使用它的公式一致 | 一致／不一致／需確認。不一致時寫出是哪一個使用處、差在哪裡（單位、IT 對設施、輸入對輸出 token、每 GPU 對每架、名目對實質、年對月等） |
| 問題類別 | 可複選：**T** 時點過時或與現況不符；**G** 應隨世代或時間變化卻是單一值；**U** 單位或口徑不一致；**S** 無來源或來源薄弱，而且敏感度高；**E** 有未處理的證據對應這一格（對照第 0 段 C2）；**R** 數值合理性可疑（依一般知識判斷，需外部查證）；**D** 定義不清（列標籤與公式用途對不上）。沒有問題就填「—」 |
| 嚴重度 | 高／中／低。高＝在 m 路徑上，或屬 Load_Bearing／Sensitivity 頁的高敏感度輸入，而且有 T、G、U、S 中的任一項 |
| 理由 | 一到兩句，說明為什麼標這個類別 |
| 需外部查證 | 是／否 |

規則：

- 判讀依據是工作簿內的列標籤、說明欄、來源欄、Gov_Map 與 Decisions，再加上一般知識。**原則上不做網路搜尋。** 只有在嚴重度為「高」、而且是否有問題取決於一個可查的事實時，才可以搜尋，總數不超過 20 次，每一次都要記在明細。
- 物理或定義常數（例如每年小時數、FP8 每元素 1 byte）標「否、無時點」，不列為問題。
- 同一列的世代或層級欄如果是同一種問題，可以合併成一列判讀，但明細要寫明涵蓋哪些格。
- 「不確定」與「沒問題」要分開；「沒查到」與「不存在」要分開。
