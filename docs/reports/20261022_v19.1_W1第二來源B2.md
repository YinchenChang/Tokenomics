## 0. 一句話結論

Arch 頁 C 欄（Luna＝DeepSeek V4-Flash 類）原與 Pro 共用 top-k 1024，Flash 官方 config 是 512。本版新增 Flash 專屬紀錄 SRC_MOD_106（512），Arch!C17 由 4224 改為 2176（512 × 4 ＋ 128）。變動只經 Arch!C17 往下游傳：Luna 每 GW token 增加最多約 17.8%，m（`L1_MFleet`）下降 2.70%，回本主口徑 `L1_LReqFleet_IdNoK` 不變，`L1_LTotalFleetVDisc` 幾乎不變（+0.0002%）。
