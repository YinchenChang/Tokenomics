## 結論（先讀這段）
1. **隱含 m（OpenAI 2025，毛額營收，層級組合單價 1.96 $/M）**：訂閱路線 **3.49**（0.94–28.95）、API 路線 **0.65**（0.35–2.61）、合併 **1.74**（0.85–5.72）。全部是 **Derived**，而分母（付費 token 數）來自模型自己的 Alloc 假設（Assumed），**不是實測**。
2. **合併 m > 1 不可信，問題在分母**：OpenAI 不揭露 ChatGPT 的 token 數；模型以「每日 25 億則 × 每則 4,000 token」推出每日 16.5 T。若改用 Epoch 的 10–100 T／日，合併 m 變成 2.87–0.29；跨一個數量級。模型內 `L1_ScaleServe`＝18（支出路線的服務算力是 token 路線的 18 倍）指向同一件事：**token 路線的需求很可能低估**，所以隱含 m 被高估。
3. **比較可信的兩個點都在 0.3 附近或以下**：(a) API 2026 Q1 時點（15B tok/min 是一手，API 營收占 15–25% 是 Analogy）：**0.31**（0.19–0.75）；(b) 程式代理訂閱（Claude Code 企業平均 $13／活躍日、p90 <$30，一手）：$200 方案 0.32–0.92、$20 方案 < 0.1。兩者都低於 Gov_Map 區間中段，支持「重度用戶與程式代理把 m 往下拉」的方向。
4. **單價結構本身就讓 m 偏低**：程式代理的輸入占 99%+、快取命中 92–99%（Requesty 91.9%、Pegatron 實測 99.3%），以 Sol 有效價計每 token 實收只有參考請求的 **0.11–0.20 倍**；OpenRouter 全市場平均（6,000／400）在 χ＝0.55 下為 0.78 倍。這部分在 m 的定義內（m＝實收單價 ÷ 參考請求有效單價），是 m < 1 的獨立來源，不依賴用戶數。
5. **付費用戶數有可用時間序列**：ChatGPT 消費訂閱 15.5M（2025-01）→ 20M（2025-04）→ 35M（2025-07）→ >50M（2026-02、一手）；付費商用用戶 2M → 3M → 5M → 7M 席次 → >9M（2026-02、一手）。Anthropic 只有商用客戶 >30 萬（2025-09）與 >$1M 客戶 >500（2026-02），**消費訂閱數未揭露**。
6. **營收拆分**：OpenAI 消費訂閱占 75%（2024-10）、約 70%（2025-10），「企業」>40%（2026-03，一手，口徑未定義）；API 拆分 2024 年中以後沒有可靠數字。Anthropic 2025（機密 S-1 經 Reuters）：用量計費 3.8、訂閱 0.789（17%）、雲端市集 2.16（47%）、付給平台約 0.351 $B（市集營收的 16%）。
7. **每付費用戶年 token 沒有任何公司揭露**；可用的換算：ChatGPT 每付費訂閱者約 44 M tok／年（11–106，Derived）、每日約 30 則；Claude Code 企業開發者約 6 B tok／年（Derived，94% 為快取讀）；兩者差 100 倍以上，**所以路線必須分開**。
8. **建議**：CTL_Monetize 基準 1 與區間 0.3–1.0 **暫不改**（J1 (a)）；B 段先把追蹤區塊上線，並把「模型 token 路線」與「外部 token」兩種分母並列（J2）。DB_Evidence 登錄提案 23 筆：採用 11、部分採用 7、不採用 3、待查 2。
