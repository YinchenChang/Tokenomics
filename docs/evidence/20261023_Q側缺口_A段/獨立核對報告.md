## 結論（先看這裡）

- **數值層：0 項不符。** TK 輸入 10 項全部與 `20261023_Tokenomics_v21.1.xlsx` 具名範圍逐位相同；公式頁 57 個數值格以 Python 獨立重算，容差 1e-6 全部通過；公式引用列無 off-by-one。
- **邏輯層：恆等式與價格因子方向正確。** 9a 比值 1.9422 ＝ 204 ÷（GW×持有成本）1.9339 × 1.0043，差異全來自 B4_Serve 四捨五入（0.41 對 0.41176）。「所需價格因子＝總缺口×s÷GW 因子」：低端用 GW 高、s 低，高端用 GW 低、s 高，方向正確。
- **文字一致性：5 項需修正，1 項需說明（皆不改變主結論）。**
  1. 「結論」第 3 點寫「平均 GW 須 1.84–2.25」，「三因子」B15／B16 算出 **1.72–2.32**（兩者用不同的總額：17.2–21.0 對 16.06–21.66）。同一件事兩個數字。
  2. 「衝突裁定」C3 寫 Microsoft 帳推 **1.39**–2.33，公式 B19 ＝ 1.3847，應為 **1.38**（README 同誤）。
  3. 「支出路線對照」證據低端倍數用 **1.5**，「結論」「待判斷」J5 的證據區間是 **1.4**–2.2（中點 1.8 對應 1.4–2.2，不對應 1.5–2.2）。
  4. README 的 J3 與審閱檔的 J3 是不同事項（README：價格因子是否由 0.85 改區間；審閱檔：9a 是否構成 Q 側修正，該事項在審閱檔為 J5）。
  5. README「兩年一致性」寫「12.8–16.0 億／GW·年」，單位錯：應為 12.8–16.0 **十億美元**（128–160 億）／GW·年。
  6. 價格因子上端 2.18 是把 s 上限截在 1 的結果；查核帳上界 216.6 億超過 204 億，不截則為 2.32（與 Microsoft 帳 2.33 相近）。文字沒說明這個截斷。
- 外部值：抽查 6 項，6 項相符（見表）。Epoch 16 億頁面抓取被拒（未核對）。
