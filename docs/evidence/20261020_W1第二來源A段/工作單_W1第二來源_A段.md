## 每筆要做的事
1. 讀輸入列：SRC_ID、指標、數值、單位、口徑、適用對象、日期、原出處、立場說明。
2. 找「同指標、同口徑、同對象」的第二來源，且發布者不是原紀錄的利害關係方（例如 OpenAI 自揭營收 → 找 The Information／Reuters／Epoch 的獨立數字；NVIDIA 規格 → OEM 規格表如 HPE／Dell／Supermicro）。
3. 依 `stage2_source_check_rules.md` 填讀取結果 R1–R6、等級、摘錄（英文 ≤15 字，附網址與讀取日期）。「找不到」≠「不存在」。
4. 分類（每筆一個）：
   - **A 一致**：找到獨立第二來源，值相同或落在原紀錄區間內（換算須列式）。
   - **B 不一致**：找到獨立第二來源但值不同；列差異 %。
   - **C 自揭即事實**：原紀錄本身就是事實的發布者（官方牌價頁、官方規格表、模型 config 檔、財報）；獨立第二來源只能轉載。仍盡量找一筆轉載或官方原頁並註明。是否免除第二來源由 Andy 判斷，代理不決定。
   - **D 已搜尋未找到**：列出所用查詢詞（至少 3 個）。
5. 每查完一筆就寫入輸出 CSV（追加），中途中斷也保留進度。
