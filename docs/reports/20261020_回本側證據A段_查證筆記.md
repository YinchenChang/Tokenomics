4. **推論支出口徑**：2026 年新增資訊支持「84 億是服務用戶推論的合理估計」，但口徑差異仍未被一手資料解開（見任務 2）。這點與計價倍數同等敏感。

## 任務 1：合約換算

### 1.1 假設與換算方法
- 持有成本（Tokenomics，$B／GW-IT·年）：Hopper 9.70、GB200 8.83、GB300 10.89、VR200 12.23。
- 設施→IT：除以 PUE，我用 **1.25**（區間 1.2–1.3 另列）。Epoch 對 Abilene 的估算（1.2 GW 設施 ≈ 843 MW IT，比值約 1.42）作為高端敏感度。
- 每 GPU 小時：容量與 GPU 數都揭露的合約只有「IREN 容量」，但 GPU 數未揭露，所以**所有合約的每 GPU 小時皆無法換算**（不自行猜 GPU/MW）。
- 隱含計價倍數 = 合約每 GW-IT 年金額 ÷ 同世代持有成本。

### 1.4 對 0.85（0.73–1.17）的含義
- 落在區間內：IREN 0.89、CoreWeave 0.90、Oracle 0.94、Rittenhouse 0.92，全部**高於 0.85 但低於 1.0**，中位數約 0.9。
- 沒有證據支持 0.73 的低端。
- 超出範圍的是 Nebius 下界（對 GB200 ≥1.31），顯示對 Microsoft 的某些合約價可能 >1.17；但容量分配不明，只作警示。
- 方向性結論：**「價格÷經濟持有成本」的直接觀測值偏向 0.9–1.0，而不是 0.85；若用觀測值，所需 L 變小（對你的回本判斷有利）**。
- 敏感度（營收 130.7 億、推論 84 億）：所需 L = 0.6427 / SB。SB 0.73→0.880；0.85→0.756；0.89→0.722；0.94→0.684；1.00→0.643；1.17→0.549。
- 反方證據（交叉驗證）：Oracle 內部資料顯示 AI 雲毛利「極薄」（The Information 轉述，Seeking Alpha 摘要：平均約 16%，有時低於 10%；TipRanks/The Fly 僅稱 razor-thin，無數字），換算 價格÷會計成本 ≈ 1/(1-0.16) = 1.19，與你目前採用的 1.16 一致，支持「價格÷會計成本」這一步。但這只驗證乘法鏈的第一段，不驗證「會計÷經濟 0.73」那一段。
- 重要偏誤：（a）供應商的 5 年合約短於 GPU 經濟壽命，殘值歸供應商；（b）合約含預付款（IREN 20%）、可能含電力或不含，各家不一；（c）Microsoft 作為 OpenAI 股東（約 27%）與 OpenAI 大量以 Azure 額度（in-kind credits）支付，OpenAI 的實付價可能與市場價不同。

### 2.2 三個數字（84／75／126）差異的最新解釋
- 沒有找到一手資料把三者對齊。我能找到的可信解釋有三點：
  1. **範圍不同**：75 億是公司帳上 cost of revenue（會計科目）；84 億是投資人簡報裡的「推論」定義；126 億是 Microsoft 端 Azure 推論帳單推估，Zitron 稱含研究推論。
  2. **額度與現金**：The Register 與 qwe.edu.pl 皆指出 Microsoft 端數字可能包含非現金的 Azure 額度，故不等於 OpenAI 帳上成本。
  3. **非 Azure 供應商**：75 億營業成本應涵蓋 CoreWeave、Oracle、AWS 等；84 億是否含這些，未說明。
- 安全邊際內部矛盾（safeguard.sh 也提醒）：75 億小於 84 億，兩者不可能同時是同口徑的「直接成本」。若 84 億為推論而 75 億為營業成本，那 84 億 > 75 億代表有一部分推論被記在 R&D（例如免費用戶或研究側用量）或是額度/折讓處理不同。**此為推測，無來源證實**。
- 對你模型的影響（SB=0.85、營收 130.7）：
  - 60.47 億 → 所需 L 0.544
  - 75 億 → 0.675
  - 84 億 → 0.756
  - 88 億 → 0.792
  - 126 億 → 1.134（不可能回本）
  回本與否強烈取決於口徑；84 億與營業成本 75 億之間差 9 億，單這一項就讓所需 L 差約 0.08，比計價倍數的不確定性（0.85→0.89 約 0.03）更大。
