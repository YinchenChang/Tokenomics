### 1.2 Interface 新列（新具名範圍，C:Q 15 欄，口徑與對應基準列相同，只把 C18 換成 `CTL_ProdDerate`）
`IF_FullCost_Luna_Prod`、`IF_FullCost_Sol_Prod`、`IF_FullCost_Astra_Prod`、`IF_RevGW_Luna_Prod`、`IF_RevGW_Sol_Prod`、`IF_RevGW_Astra_Prod`、`IF_RevGWFleet_Prod`。

### 1.3 實作方式與階段閘（CC 先評估，再建置）
C18 會改變 SLO 下的批次選擇，效果非線性（不可用倍數近似）。可能需要從 C18 起複製一段推導鏈（Calib → Perf_Batch → Serving → Unit_Cost → Amortize／Cache_Store → Theory_Rev，以實際依賴為準）。
- 開工先估：需複製的公式格數、全簿公式格增幅、預估重算秒數。
- **停止條件**：公式格增幅 > 25%，或全簿重算預估 ≥ 2 秒，或需要改動既有公式邏輯（不只是新增）。任一成立時，**不建置 X1**，在報告「待 Project 判斷」列出估計值與至少兩個替代做法（例如只做 VR200、Rubin Ultra 兩欄；或只做 FullCost 不做 RevGW），其餘各節照做。
- 未觸發停止條件時建置，報告列出實際增幅與秒數。

### 1.4 自我檢查（寫入 Checks，計入 GOV_Errors）
