# W2 優先查證：0.6／1.9 GW 是否含 Azure；2025 Azure 占比

分支 `claude/evidence-q-gap-a`；基準 master `4ef0b0a`。本檔為 A 段部分成果（W2 先行），W1、W3、W4 尚未開始。

## 結論先行（STATUS）

1. **0.6／1.9 GW 是否含 Azure 提供的容量：官方未明說；最佳讀法是「含」。**
   - OpenAI 官方（Friar 部落格，2026-01-18）只給 0.2／0.6／~1.9 GW，沒有說明 IT／設施口徑，也沒有說明是否含合作夥伴容量。
   - Epoch（第三方）把數字解讀為「OpenAI 租用的資料中心的電力容量」，以 IT 電力為主（約 90%），推定含租用的雲端容量（Microsoft、Oracle、CoreWeave）。這是 Epoch 的推定，不是 OpenAI 聲明。
   - Epoch 另認為「Microsoft 為自家產品跑 OpenAI 模型的算力」很可能不在 1.9 GW 內（"we think they probably do not"）；該部分另估約為 OpenAI 自有機隊的 25%（上限 50%）。
2. **2025 年 Azure 占 OpenAI 算力比例（季度或年底）：已搜尋，未找到任何官方或可靠的百分比。**
   - 只有間接指標：洩漏文件的 Azure「inference spend」（Zitron，2025-11）2025 Q1 20.75、Q2 29.47、Q3 36.48 億美元；H1 合計 50.2 億。
   - 對照 Epoch 引用的 2025 雲端總支出約 160 億：Azure 推論支出前九個月 86.7 億，已占其 54%。但此為「推論支出」，非全部算力，且與 84 億（推論全年）衝突，定義不明，不能直接當占比。
3. **對 chat 端問題的影響（只給證據，不下模型結論）：**
   - 因 1.9 GW 很可能已含 Azure，把缺口歸 GW 因子的理由不成立於「漏算 Azure」這條路；GW 因子的主要不確定性仍是年底值對平均值的內插，與 IT／設施口徑（口徑只會使 IT 更低，方向使缺口更大）。
   - 若 Epoch 的「Azure 代管他人產品推論不在 1.9 GW」成立，則 84 億（若不含該部分）與 1.9 GW 口徑一致，不構成額外缺口；若 84 億含該部分，則分子含了分母沒有的項目，屬口徑因子。
   - 結論：目前證據不足以把缺口改歸 GW；偏向維持價格因子＋口徑因子，待 W1（84 億定義）與 W3 補齊。
