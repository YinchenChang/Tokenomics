## 3. 獨立分析
- **一次性與趨勢**：2024 年中以後的降幅大多是兩件一次性事件（快取折扣引入、個別新世代降價）；去除快取後約 0%。若未來不再有這類一次性降價，g 會接近 0，回本較可能；若新世代持續「同價但更大的模型」，牌價持平但每 GPU 的 token 產出下降——這不在 g 裡，而在模型規模（Q2 的 `d2_model_*` 情境）裡，兩者不可重複計算。
- **漲價訊號**：Google 已公告 Argon 與 Flash 系列翻倍、Sonnet 5 原定漲價後取消、OpenAI 5.5／5.6 Sol 曾漲到 $5.58。2026 年中階價格出現雙向移動，這是 2024 年以前沒有的現象（反方證據：同時期 GPT-6 Sol 與 Sonnet 5.5 降回 $2）。
- **同業收斂**：2026-10 三家中階報價完全相同（$2／$0.10／$10），顯示價格錨定在競爭均衡，而不是成本加成。
- 方向檢核（第 10 條）：E1 縮窄區間低端（−25% → −20%）——收窄；E1 高端不變——保留；E2 區間 0.05～1.0 → 0.15～0.7——收窄（低端依讀法甲上移、高端依租金比下移）；E3 不變——保留；E4 不採——保留。收窄 2、保留 3。兩項收窄都使 L 的低端上移（偏向回本），請留意這是同一方向的偏移；理由分別是 −25% 只來自 2023–24 重估、ρ 0.05 是 token 價格比未乘吞吐倍數。
- 涵蓋檢核（第 11 條）：[A] L 的恆等式（L 公式、所需 L）已做；[P] 硬體壽命與折舊、每 GPU 吞吐倍數（活頁簿內 Luna／Sol 3.34～3.41）已做；[I] 價格錨定、競爭收斂、長約的風險轉移已做。

## 4. 判斷
- 立場：E1～E3 建議採用（小幅調整與改標記）；L 的判讀**未定**（Agree with 「未定」，不支持「未回本」作定論）。把握：中低。
- 基準情境（約 50%）：g −9%～−4%，L 0.66～0.75，略低於所需 L，不回本但差距小於 15%。替代 A（約 30%）：一次性降價不再、g 約 0%，L 約 0.83，回本。替代 B（約 20%）：競爭再起、g −15%～−20%，L 約 0.55，不回本且差距擴大。
- 主要驅動：(1) 中階牌價是否還有一次性降價（快取、世代）；(2) ρ 的真實 GPU 價值比（需小模型吞吐倍數）；(3) 所需 L 本身（持有成本 ÷ 實收營收，含推論支出與計價倍數）。
- 證偽條件：2027 年中以前中階混合價跌破 $1.5（g < −15%）→ 替代 B；Google 漲價落地且 OpenAI／Anthropic 跟進 → 替代 A。
